# Order-Management-System

A custom C#/.NET desktop application developed for a real-world company to manage customer orders, generate bills, and print them in a professional A4 format.

🔒 Private Project: The source code is not publicly available because the system was developed for a private company.

# 📌 Overview

The Order Management System was developed to simplify the company's daily order and billing process.

The application allows the manager to enter customer and order information, generate a properly formatted bill, preview it, and print it directly on A4 paper.

The system was designed based on the company's actual workflow and requirements.
